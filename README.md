# Motion Lab · 놀이기구 데이터 진로탐구

스마트폰(phyphox)으로 측정한 놀이기구 운동 데이터를 올리면, 진로별 탐구 주제 21개에 맞춰 그래프와 값을 계산하고 결과보고서를 내려받을 수 있는 웹 도구입니다.

**바로 쓰기:** https://ray-math.github.io/labs/motion/

처음 열면 에버랜드 모니모러쉬 실측 자료(2026-10-31 10:03)와 그 시각의 시간별 날씨가 보입니다. 내 파일을 올리면 내 데이터로 바뀝니다.

## 사용 순서

1. phyphox "통합 측정"으로 기록하고 CSV(또는 zip)로 내보냅니다. 출발 전 3초 정지, 폰은 지퍼 주머니에 고정합니다.
2. 위 주소를 열고 **내 측정 파일 넣기**로 파일을 올립니다.
3. 탐구 주제를 고르면 그래프와 값이 내 데이터로 계산됩니다. "주제별 참고 결과" 탭에서 가상 데이터 결과와 해석 방법을 비교합니다.
4. **기초자료 보고서 다운로드**를 누르면 계산값·그래프·자동 해석 초안에, 탐구 동기·가설·연계 교과·내가 한 일·시행착오·진로 연계·후속 탐구·참고 자료·활동 기록을 적는 칸이 들어간 보고서(HTML)를 받습니다. 빈칸을 채우고 **PDF로 저장**을 누릅니다. AI(ChatGPT 등)로 보고서를 다듬을 때는 **AI에 넣을 파일(.md)**을 올리세요. 그래프 설명과 숫자, 지어내지 않도록 하는 지시문이 들어 있습니다.

모든 그래프 맨 앞에 **보고서에 쓸 글**(먼저 알아 둘 말, 고민과 실험 설계, 측정 결과 분석, 얻은 것, 한계와 개선)을 모니모러쉬 실측값으로 적어 두었고, 그래프 설명과 분석 방법은 토글 안에 있습니다. 시간 그래프 배경에는 리프트·낙하·주행 같은 구간 이름이 표시됩니다. 내 파일을 올리면 숫자가 내 값으로 바뀌고 보고서 문장은 빈칸이 있는 틀로 바뀝니다.

올린 파일은 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.
